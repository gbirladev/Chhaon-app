# Trademark clearance brief — candidate product name

Prepared 2026-10-11 for a trademark attorney. This is a first-pass register check done by the founder, not a legal opinion. All records were read on the IP India public search on 11/10/2026.

## The product (one paragraph)

CareLink (working name, to be replaced) is a family health-care service for adult children who live away from their ageing parents in India. The child uses a web app. The parent installs nothing and receives WhatsApp messages: medicine reminders with a "Taken" button, a daily "are you okay?" check-in, and appointment reminders. The child gets alerts when a dose is missed, can share the parent's profile with siblings, and can create an emergency card link (medicines, allergies, contacts). Initial markets: India and Indian families abroad. Parent-facing messages are in Hindi and English.

## Candidate names

1. **Smaranam** (preferred candidate; Sanskrit "remembering")
2. Smarana / Smaran (variants; being checked, Smarana now looks unusable, see below)
3. Second choices not yet searched on the register: Haalchaal, Tasalli

## Classes we expect to file in

- 9 (downloadable software and apps)
- 42 (online software services)
- 44 (health and medical services)
- 45 (personal and social services), possibly
- We intend to avoid Class 35 unless advised otherwise.
