Daily care: the doses, one day at a time

Today screen · live

Taken, missed, late and pending doses for the day, with the check-in. It refreshes by itself, and one tap switches between parents.

Taken late · live

If a parent taps Taken after the dose was marked missed, it still counts and is shown as late, not lost.

Ten Today styles · live

Each caregiver picks how the Today screen looks, from a plain list to a route through the day.

Medicines · live

Name, dose, before or after food, any number of times a day, and a photo of the strip so the parent recognises it.

Pause a medicine · live

Stop one medicine’s reminders when a course ends or a doctor changes it, and restart later. Nothing is deleted.

Stock and refills · live

Type the number of tablets left. One is used per Taken, and the family is warned before it runs out.

Live = in use now · Built, off = finished and tested, switched on later
