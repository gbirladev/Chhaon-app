Appendix · feature briefs 4 of 6

The parent’s side: only WhatsApp

WhatsApp only · live

The parent installs nothing and has no account or password. Everything arrives as a normal WhatsApp message.

Permission first · live

Before any reminder, one message asks Yes or No. STOP ends everything, and START brings it back.

Reminders · live

At the right time a short message names the medicine and dose, shows the photo, and has a Taken button.

One message per time · built, off

Medicines due at the same time arrive as one message with a single Taken all button, not five buzzes.

Hindi and English · live

Every message, and the whole app, in the language chosen for that parent. More Indian languages will follow.

Nothing to learn · live

Buttons say Taken, I’m okay or Call me. The parent never needs to type anything.

Live = in use now · Built, off = finished and tested, switched on later
