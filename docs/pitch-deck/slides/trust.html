Safety and trust

Health information deserves full care

PrincipleHow it is built
ConsentThe parent says yes on WhatsApp before any message. STOP always works.
PrivacyEach family’s data is kept apart. Files sit in private storage. No health data in logs.
SafetyIt never diagnoses or tells anyone to change a medicine. Always “not medical advice”.
ControlDownload all data or delete the account at any time. The emergency link can be revoked.
LawDesigned with India’s Digital Personal Data Protection Act 2023 in mind.
